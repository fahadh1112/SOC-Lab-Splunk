# SOC Lab Setup using Splunk Enterprise

## Project Overview

This project demonstrates the setup of a Security Operations Center (SOC) lab using Splunk Enterprise and Sysmon on Windows 11.

## Objectives

- Install Splunk Enterprise
- Install Sysmon
- Configure Windows Event Logging
- Configure Splunk Universal Forwarder
- Forward Windows logs to Splunk
- Analyze security events

## Tools Used

- Splunk Enterprise 10.4.1
- Splunk Universal Forwarder
- Sysmon
- Windows 11
- Oracle VirtualBox
